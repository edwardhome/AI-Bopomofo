# AI注音輸入法 1.1.0

更新時間：2026-11-13T23:47:18+08:00

## 這次更新

- **F 按下即顯示原字**：標準注音預覽 ㄑ、英文預覽 f；超過長按門檻才撤回預覽並進入數字／符號層。門檻內接任何下一鍵都正常打字，取代原本立即組合鍵，減少快速輸入誤觸。
- **Shift＋F 可長按轉小寫**：Shift＋F 優先英文大小寫，不啟動 F 分層。開啟 Shift 英文組字後，長按首字母 F／S 可轉為 f／s；首字母與 F 分層時間分開設定。
- **可自訂 QWERTY 映射**：在「偏好設定 → F 分層」修改符號、輸入 Unicode、留白停用或還原預設。既有長按時間保留；F、退格與 Enter 保留控制用途。
- **精簡選單**：保留 10 個常用操作，AI、診斷、詞庫匯入／匯出等集中在「工具與詞庫…」視窗。繁簡與半形標點快捷鍵保留。
- **統一 SQLite 詞庫管理**：使用者詞、工程詞與中文別名在同一份版本化管理詞庫中編輯，支援離線匯入預覽、核准、匯出與回復。原有私人詞庫及內建資料保留，不自動同步雲端。

## 安裝與注意事項

下載 `AI-Bopomofo-1.1.0.pkg` 安裝；`AI-Bopomofo-1.1.0.zip` 是 app 備用封裝。兩者適用 Apple Silicon 與 Intel Mac。基本功能目標 macOS 13 以上；Apple 模型功能需符合其系統與模型可用條件。

本版採 ad-hoc 簽章，未經 Developer ID 簽署或 Apple 公證。請核對 `checksums.txt`，依 macOS 系統提示自行核准。更新後若 F 分層失效，請在系統輸入監控重新加入新版 app；程式不繞過權限驗證。

詳見 [安裝說明](https://github.com/edwardhome/AI-Bopomofo/blob/v1.1.0/docs/installation.md)、[F 分層操作](https://github.com/edwardhome/AI-Bopomofo/blob/v1.1.0/docs/quick-symbols.md)及 [SQLite 詞庫操作](https://github.com/edwardhome/AI-Bopomofo/blob/v1.1.0/docs/lexicon-learning/unified-sqlite-user-guide.md)。
