# Markdown 與獨立 F 分層

AI注音輸入法 0.4.0 新增不依賴 Kanata 的快速數字／符號層。鍵位由提供的 Kanata 設定對照而來，程式不讀取設定檔、不呼叫 Kanata，也不建立全域鍵盤攔截或送出虛擬按鍵。

在輸入法選單勾選「長按 F 輸入數字／符號」。按住實體 F 約 200 毫秒，候選視窗會顯示鍵位提示；繼續按住 F，再按對應按鍵即可連續輸入。放開 F 或按 Esc 返回中文。短按 F 仍交給原本的注音處理；200 毫秒內接著按另一鍵，會先補回 F，維持快速中文打字的順序。

| 按住 F 時再按 | 輸入 |
| --- | --- |
| Y U I | 7 8 9 |
| H J K | 4 5 6 |
| N M , | 1 2 3 |
| Space、. | 0、小數點 |
| Q W E R | / * - + |
| O P、[ ]、反斜線 | { }、[ ]、反斜線 |
| A S D G | < > = > |
| L ; ' | 冒號、分號、雙引號 |
| Z X B / | 單引號、直線、度數符號、問號 |
| 1 2 3 4 5 6 7 8 9 0 | ! @ # $ % ^ & ~ ( ) |
| - =、反引號 | 底線、單引號、反引號 |

這裡依照原設定使用 **Y U I** 作為數字上排。未配置的 T、C、V 在分層中不輸入文字，避免意外混入注音。分層輸出的是文字，並不模擬硬體數字鍵盤。

也可以從選單「快速數字／符號」直接進入，不必按住 F；按 Esc 或 Enter 離開。視窗使用原有候選介面，方向鍵瀏覽、Tab／Page Down 換頁、Page Up 回頁，也能點選符號。候選標示是實體鍵位，與中文選字鍵 `asdfghjkl` 分開。

## 操作界線

- 在空白組字或已完成注音音節的中文字串後，可以進入 F 分層；之前的中文會先送出。
- 正在輸入未完成的注音音節、英文／ASCII、選字狀態時，不攔截 F。先完成音節／選字或送出英文即可使用。Shift＋F 仍走原本的英文入口。
- Cmd／Ctrl／Option 快捷鍵不套用數字符號映射。切換應用或輸入來源時會取消計時與分層。
- 此功能只在 AI注音輸入法收到輸入事件時有效。其他輸入來源、密碼欄、Vim 普通模式與忽略 IMK 事件的程式不在此版本保證範圍。
- 首次安裝預設不啟用 F 長按，避免改變既有中文節奏；本次使用者授權的本機安裝會啟用，選單可關閉。測試時請停止 Kanata，避免兩者同時處理 F。
- 按住 F、按住數字對應鍵、先放 F 的情況，會抑制尚未放開的對應鍵重複事件，避免數字變成注音。各應用是否完整提供 key-up 仍須實機驗證。

## Markdown 優先

新偏好設定預設使用半形標點；既有使用者的明確設定不會被新版預設覆寫。本次安裝會啟用半形標點。單按反引號直接輸入半形字元；Ctrl＋反引號保留 Big5 功能。若有未完成的中文字串，反引號會連同畫面上已有的文字／注音一起送出，不丟字。

原有的標點清單可在「進階工具 → 反引號開啟標點清單（舊版操作）」恢復。原有工具、詞庫與繁簡選項集中在進階工具，主選單保留常用入口與設定。

標準注音 `ji3` 對應「我」，目前仍顯示注音符號。原始英文鍵顯示與 Vim 專用英文模式列為後續討論，不在本版混入自動語言猜測。

## 人工驗收

先確認選單顯示新名稱與版本 0.4.0，Kanata 已停止。依序測試：短按 F、快速連打 F 與其他注音、長按 F 後 Y／H／N／Space／R、放開 F 再輸入中文、長按期間按 Esc、切換應用後不留分層、Shift＋F 的英文組字、半形反引號與 Ctrl＋反引號、將選字鍵改成 asdfghjkl 後重新開啟設定。

至少在 TextEdit、瀏覽器及常用編輯器分別確認。純邏輯測試與編譯成功不代表這些人工項目已通過。
