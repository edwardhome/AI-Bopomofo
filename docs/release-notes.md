# 0.6.5-alpha 輸入法選單指令

使用者確認「進階工具」子選單內的診斷、半形標點、匯入與編輯使用者資料等指令皆沒有作用。將這些指令移回第一層，以分隔線及標題區分，不再放入子選單；保持原指令、偏好與快捷鍵。診斷開始時顯示成功提示；安全輸入或無法建立檔案時也會顯示原因，不再靜默失敗。

中文標點既有規則不變：關閉「使用半形標點符號」後，Shift＋逗號為「，」、Shift＋句點為「。」；開啟時為半形逗號與句點。普通注音鍵位不變，英文／ASCII 與 F 符號分層保持原行為。雙 Shift 本身尚待取得實機診斷結果，不能把選單修復等同於雙 Shift 修復。

# 0.6.4-alpha 可核對的雙 Shift 診斷檔

0.6.3 的系統日誌與獨立測試訊息均無法讀回；改為寫入本機使用者快取內的 `org.aibopomofo.inputmethod.AIBopomofo/shift-diagnostic.log`。仍須手動開啟，最長 20 秒、80 筆事件加一筆結束記錄；每次開啟覆寫上次報告，預設不收集。欄位僅含事件類別、匿名控制器、單調時間、修飾鍵與模式狀態。檔案僅供目前使用者讀寫；Secure Input 停止收集，寫入失敗停止診斷而不影響輸入。切換邏輯未變，尚未修復雙 Shift。

# 0.6.3-alpha 雙 Shift 限時診斷

0.6.2 實機仍無法雙擊 Shift 切換，注音與選單切換正常。本版不更改手勢判斷，新增「進階工具 → 診斷雙擊 Shift（20 秒）」；預設關閉，由使用者手動開啟，每次最多 20 秒、80 筆事件加一筆結束記錄。只記錄修飾鍵狀態、重設原因、匿名控制器識別與切換結果，不記錄文字、按鍵碼或用戶端名稱。遇到 Secure Input 立即停止，不新增全域監聽或變更 F event tap。

# 0.6.2-alpha 雙 Shift 修飾鍵辨識

針對 0.6.1「選單可切換、雙 Shift 完全不切換」回報，雙 Shift 改以修飾鍵狀態的按下／放開轉換辨識，取消依賴事件中的左右 Shift 實體鍵碼，計時改用單調遞增的本機接收時間。已處理的切換事件回報為已接收。保留大小寫／組合鍵、長按與重疊 Shift 的取消規則；不增加全域監聽、不更動 F event tap。

新增重複空閒狀態、組合鍵釋放順序、完整重疊 Shift 及無效時間案例。真實 IMK 事件路徑仍需使用者驗收，不能只依純邏輯測試宣稱故障已排除。

# 0.5.4-alpha F 放開事件監聽

依使用者授權新增輸入監控權限入口。F 手勢使用 session listen-only key-up 監聽，不再依賴按鍵狀態輪詢；超過 100 毫秒才啟用，放開退出，長按期間不顯示選單。未授權或監聽失效時回復普通輸入。詳見 [F 操作與權限](quick-symbols.md) 及 [隱私說明](privacy.md)。

MixedInputCore 19 項測試通過；以事件釋放、100／101 毫秒、監聽失效與取消測試取代不再使用的狀態輪詢測試。沒有執行 GUI／hosted 測試或聲音。跨應用仍待實際驗收。

# 0.5.3-alpha 無選單按住 F 分層

長按 F 的分層不再顯示候選視窗或提示選單。超過 100 毫秒且確認實體 F 仍按著才進入，放開退出；不再採用再按 F 切換。從選單手動開啟的快速符號工具仍保留原介面。

查詢來源改用硬體 HID 按鍵狀態。若無法確認按下，回放原 F，不進入可能無法自動退出的分層。這表示系統不提供硬體狀態時長按功能不可用，需要實機確認，不能宣稱已解決所有 macOS／應用相容性。

# 0.5.2-alpha F 分層回歸修正

修正 0.5.1 將系統查詢的「未按下」直接當成 F 放開，可能在 100 毫秒門檻前取消長按的問題。現在只有查詢確實觀察到按下後，才採信後續放開；正常 key-up 仍直接退出。分層中再按一次 F 也可退出，重複按鍵事件不觸發退出。

若應用不傳送 key-up，且系統按鍵狀態不可用，仍須再按 F 或 Esc 離開；不宣稱此限制已完全解決。保留 100 毫秒門檻及原有中文、英文、FM 功能。

# 0.5.1-alpha F 長按修正

F 長按門檻由 200 毫秒調整為 100 毫秒。手勢有效期間檢查 F 是否放開，補救應用未傳送 key-up 時分層可能停留的問題；Esc 離開時也會清除手勢與計時器。短按仍補回原本注音，直接從選單開啟的符號層仍以 Esc／Enter 離開。

新增門檻邊界、漏掉放開事件、短按只回放一次及取消後不重入的純邏輯測試。MixedInputCore 共 18 項通過；實際跨應用按鍵行為尚待人工確認。此候選版不自動安裝、不更改 Kanata、不執行音效或 GUI 測試。
