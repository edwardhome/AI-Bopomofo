# AI注音輸入法 1.0.0-dev.1

驗證紀錄時間：2026-11-09T23:44:55+08:00

此為 `feature/v1-unified-lexicon` 功能分支開發交付，未合併 main、建立標籤或發布 Release；安裝與實鍵驗收由使用者執行。

## 本版行為

- Shift＋S 短按仍保留首字大寫；持續按住字母 S，系統 repeat 到達時將尚未送出的首字母改為 s，消耗後續重複事件。先放開 Shift、仍按住 S 也可轉換。後續字母、連續大寫與提交規則維持原行為。
- 第一層選單新增「使用者與工程詞庫」，以同一套 SQLite 管理中文、英文、工程碼、Unicode 輸出與可靠讀音的中文別名關聯。
- 支援新增、編輯、刪除、選取／完整匯出、匯入預覽及核准、完整還原、上一版本回復。外部 approved 不是本機授權；中文 equivalent 關聯不會自動把中文換成符號。
- 原有文字使用者詞庫及 103 個工程詞可主動匯入管理副本。工程詞展開為 186 個不重複的輸入碼／輸出詞條，與來源表格列數不同。
- 原 JSON 1.0 保持相容；含新關聯時拒絕有損 JSON 匯出，改用完整 SQLite。SQLite 損毀時回退核准復原資料，原版本仍保留。
- 關閉 FM 背景學習不再同時關閉已核准管理詞庫；管理詞庫仍有獨立啟用開關。

## 限制與人工驗收

- 未安裝、重啟本機輸入法，未執行 GUI、模擬打字或音效測試。
- 需要使用者測試 Shift＋S 短按／長按、swift／SWIFT／mm、雙 Shift、其／去、F＋R／放開／退格，以及管理視窗的新增、匯出、還原、Secure Input 與組字期間換詞庫。
- 首字母長按依系統 repeat，沒有新增毫秒設定；不送 repeat 的應用或鍵盤設定尚未驗證。
- 管理詞庫已統一，原版 data.txt／排除檔、引擎偏好及預載工程資源仍保留。原版編輯與學習不自動寫入此 SQLite；匯入管理副本後，刪除副本不會刪原來源。並非強制把所有舊儲存改成單一檔案。
- 中文讀音沿用一至八音節限制；無法確認讀音不猜測，匯入會列出略過行號。
- 沒有雲端資料夾監看、每週同步、強制上傳、AI 語境記憶或新的背景網路傳輸。
- 未量測本版完整 IMK 按鍵 P95、長時間輸入或真實 FM 延遲；不能宣稱已達延遲目標。SQLite 讀寫、匯入解析及索引建立在管理／背景路徑，按鍵只用既有不可變索引。
- 附件使用 ad-hoc 簽章，未經 Apple 公證。安裝及系統授權由使用者本人操作。
