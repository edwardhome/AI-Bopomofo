# 故障與回復

| 故障 | 行為 |
| --- | --- |
| 佇列滿載或 try-lock 失敗 | 丟棄新增觀察，文字輸出保持原流程 |
| SQLite 無法開啟、唯讀、交易失敗或空間不足 | 停止本輪持久化並顯示狀態，不無限重試 |
| 已確認 SQLite 損毀 | 關閉連線後隔離資料庫及 WAL/SHM；保留檔案，停止學習 |
| FM 不支援、關閉或不可用 | 不部署任何建議；人工匯出／匯入與正式詞庫可獨立使用 |
| 模型不回應或程序崩潰 | 取消 UI 等待，保持名額佔用直到結束／中斷；服務 watchdog 不結束輸入法 |
| 模型資料非法 | 拒絕整批建議，觀察與核准詞庫保持原樣 |
| JSON 不合法或內容矛盾 | 拒絕預覽／核准；保留目前版本 |
| staging、驗證或原子切換失敗 | 不更新記憶體快照，原版本保持有效 |
| 目前版本損毀 | 回退有效歷史版本；所有版本失效時僅停用擴充 |
| SQLite 失效但版本檔有效 | 仍可載入、預覽及核准擴充詞庫 |

本機資料夾由系統 Application Support API 取得，不使用私人詞庫的自訂同步路徑。詞庫版本最多保留目前版加五個歷史版；不可逆清除只在明確管理操作確認後進行。清除待整理資料不刪除使用者另存的匯出檔或版本核准紀錄。

資料庫 migration 版本為 PRAGMA user_version=1。新資料庫建立 migration 在交易內完成；較新版本拒絕開啟寫入，沒有自動降版。backup 使用 SQLite backup API，不直接複製仍開啟的 WAL 資料庫。狀態窗可手動匯出一致性副本。

不要用其他電腦的 SQLite 覆寫仍執行的資料庫。跨裝置只交換 JSON，兩台電腦分別核准。若要手動處理隔離檔，先備份，再由開發者檢查；本版不提供自動猜測修復私人資料的功能。

限制：型別／來源檢查及排除清單不能保證每個短詞都沒有隱私。請於匯出前檢視選取項目。本機資料未額外加密，依賴 macOS 檔案權限及使用者磁碟保護。
