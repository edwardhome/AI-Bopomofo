# 1.2.0-dev.1：Ctrl＋數字加入詞組

更新時間：2026-11-14T00:08:53+08:00

## 狀態與操作

基於正式版 1.1.0，開發分支 `feature/ctrl-number-add-phrase`。新增功能依共同版本規則遞增第二碼；不合併 main、不建立標籤或 Release、不安裝或重啟本機輸入法。

Ctrl＋2～9 從尚未送出的注音組字取同樣字數，立即加入原有使用者詞庫，無須 Enter。預設取游標前方；「偏好設定 → 使用者詞彙」可改為後方。組字與游標不移動。Shift＋方向鍵、Enter 加詞保留。完整限制見 [詞庫操作](../dictionary.md#ctrl數字加入中文詞組12-開發版)。

## 實作與邊界

- `PhraseShortcut` 負責實體數字列、完整字元邊界與一字一讀音範圍計算，不讀寫檔案。
- `KeyHandlerInput` 以 key code 辨識 Ctrl＋2／6 等控制字元；`KeyHandler` 在一般控制字元分流前處理，但 ASCII、符號層仍走原本路徑。
- 沿用 `InputState.Marking` 的重複詞與轉換模式驗證，再委派原本的詞庫寫入。寫入失敗不執行使用者 hook；Secure Input 拒絕寫入。
- Ctrl 新捷徑支援 2～9 個完整字元。原本 Shift 標記上限保持 8；reading grid 最大跨度由 8 擴至 9，讓九字詞可成為引擎候選。
- Ctrl＋0／1、額外修飾鍵與數字鍵盤不新增加詞行為；不完整讀音、範圍不足、標點或不可靠對應拒絕寫入。repeat 不再次寫檔。
- 沿用原私人詞庫儲存與重載，不自動同步至統一 SQLite 管理副本，不把觀察資料當成已核准詞庫。
- Shift＋F 大小寫、F 按下預覽與超時才進層沿用 1.1.0，沒有新增立即組合鍵。

## 尚未執行的實鍵驗收

1. 在一般輸入欄位組出自選測試詞，不送出；Ctrl＋2 立即加詞並顯示提示，組字及游標保留。
2. 重新組字選字，確認新詞可用；再加同詞顯示已有，長按數字不反覆新增。
3. Ctrl＋9 加九字詞，之後可在候選中找到；Shift＋方向鍵仍可標記 2～8 字並以 Enter 加入。
4. 在組字中間切換方向設定；分別核對前方與後方，範圍不足不誤存。
5. 未完成注音、標點、ASCII、Secure Input、額外修飾鍵及 Ctrl＋0／1 不誤加詞。
6. 回歸 Shift＋F 長按小寫、F 短按與超時分層、退格、雙 Shift、HHKB 及 iTerm2 實鍵。

以上均為待驗收，不以模組測試代替。
