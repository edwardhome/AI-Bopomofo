# AI注音輸入法 1.3.0

更新時間：2026-11-15T21:57:16+08:00

## 這次更新

- **依 App 設定預設英文／注音**：在「偏好設定 → 應用程式」加入 App，切進該 App 時套用預設模式。功能預設關閉、清單空白，不改變升級後的既有習慣。
- **保留手動選擇**：同一 App 裡雙擊 Shift 或使用選單切換後，換欄位、視窗、分頁仍沿用本次選擇；離開 App 再回來才重新套用預設。
- **提供終端機範例**：一次加入已安裝的 iTerm2／Terminal 英文規則，不覆寫原設定，也不自動開啟總開關。規則依 App 識別碼區分，不因同名誤判。
- **保護未完成輸入**：組字、候選或 F／Shift 手勢進行中延後切換，不自動送出文字、不接受預測。Secure Input、連線不符及過期要求不套用。
- **只在 AI注音內生效**：不切換系統輸入來源、不要求額外輔助使用授權，也不讀取或修改 Vim 配置。選用 ABC 或其他輸入法時不搶回。

F 分層、Shift＋F 大小寫、Ctrl＋2～9 加詞及原有詞庫功能保留。此版規則不辨識終端機裡的 Vim、Shell、SSH、tmux 或網站；這些仍視為所屬 App。規則及總開關修改從下次切入 App 生效。

## 開始使用

1. 安裝後開啟「AI注音輸入法偏好設定 → 應用程式」。
2. 按「加入應用程式…」選取 App，或按「加入終端機範例」。
3. 確認預設英文／注音，勾選「啟用應用程式輸入模式規則」。
4. 切到其他 App，再回到指定 App；手動雙 Shift 仍可隨時調整。

[完整操作與實鍵驗收](https://github.com/edwardhome/AI-Bopomofo/blob/v1.3.0/docs/app-input-rules.md)

## 下載與安裝

- `AI-Bopomofo-1.3.0.pkg`：一般安裝。
- `AI-Bopomofo-1.3.0.zip`：app 備用封裝。
- `checksums.txt`：SHA-256 校驗值。
- `SOURCE-COMMIT.txt`：套件對應原始碼提交。

提供 Apple Silicon 與 Intel 架構，基本功能部署目標為 macOS 13 以上；舊系統與跨應用相容性仍待實測。Apple 模型功能另需 macOS 26 以上及可用的 Apple Intelligence。

app 使用 ad-hoc 簽章，pkg 未以 Developer ID 簽署，也未經 Apple 公證。請核對下載來源與校驗值，再依系統提示自行安裝。本次發布沒有安裝或重啟本機輸入法。[安裝說明](https://github.com/edwardhome/AI-Bopomofo/blob/v1.3.0/docs/installation.md)
