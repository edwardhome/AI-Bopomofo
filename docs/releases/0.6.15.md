# AI注音輸入法 0.6.15

本版正式納入與 AI 新酷音共用的個人詞庫交換契約、跨平台回歸測試與操作文件。Mac 沿用既有的詞庫匯入、預覽、核准與回復流程；相較 0.6.14，沒有修改按鍵處理、注音組字、F 分層、Shift 或模型推論邏輯。

## 共用個人詞庫

- 使用 `ai-bopomofo.lexicon / schema_version: 1.0.0` JSON，交換中文讀音、英文技術碼、大小寫、Unicode 上下標及候選提示。
- 在「AI 詞庫管理」選取要匯出的詞；另一平台匯入時仍需預覽、選取及本機核准。外部檔案寫 `approved` 不會自動部署。
- 兩台各自保存正式詞庫與選字習慣。只傳完整 JSON，不共用運作中的 SQLite、不覆寫既有私人中文詞庫、不自動同步或傳遞刪除。
- Windows 請使用包含共用詞庫功能的 AI 新酷音 1.1.1；原版新酷音、小麥注音不會因本版本發布而自動支援此格式。
- 交換檔建議放在使用者自選的同步資料夾；實際詞庫仍在各平台本機資料目錄。檔案不會自動上傳到 GitHub 或 AI 服務。

## 驗證與限制

- 正式版本的無介面測試：292 項通過、2 項既有案例略過；hosted IME 測試目標僅編譯，沒有執行 GUI、模擬打字或音效測試。
- Release 編譯及 bundle 驗證通過；app 與 ModelService 均包含 Apple Silicon／Intel 架構。首次測試目標編譯遇到舊 PCH 快取失效，改用獨立建置目錄後完整重跑成功，未修改輸入邏輯或略過測試。
- 新增 4 項 Mac 跨平台契約測試，涵蓋 7 筆 Windows 固定詞條向量、8 組非法 JSON、中文別名拒絕、本機核准、取消、重複匯入及回復。
- Windows Rust → Mac Swift → Windows Rust 的 7 筆合成資料通過完整 JSON 欄位往返；這是解析與匯出證據，不是兩端 GUI 操作驗收。部署會重新核准，Mac 不將外來 usage 統計累加為本機學習次數。
- 中文別名 `zh_aliases` 尚未納入 1.0.0。Windows 可由使用者明確接受省略後匯出基本詞條，原檔保留；Mac 仍拒絕不支援欄位。
- 傳統私人中文詞庫的自動匯出尚未完成；已核准擴充詞與選定待審詞可依既有功能匯出。
- GUI、跨應用實鍵、Secure Input 與長時間穩定性仍需使用者驗收。Windows 的極端同碼大詞庫 debug 案例曾超過 10 ms 目標，未宣稱一般輸入延遲達標。
- 自動 AI 建議延遲及模型逾時限制沿用 0.6.14；本版不新增已送出句子記憶，也不改善模型準確率。
- 傳統輸入的部署目標是 macOS 13；FM 需 macOS 26 以上且模型可用。舊系統未完成全面實機驗收。
- 附件使用 ad-hoc 簽章，未經 Apple 公證；安裝及輸入監控授權由使用者本人操作。
