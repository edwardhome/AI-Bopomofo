# 1.3.1 F 長按修正驗收

更新時間：2026-11-19T10:48:55+08:00

## 範圍

以 v1.3.0（f544222f0291d340c2605969da2f8a07c86d6136）為基準，分支為 `fix/f-hold-idle-restore-1.3.1`。2.0.0 詞彙卡開發保留在原分支，未帶入本版。這是本機驗收套件，尚未合併、建立標籤或發布 Release。

- 按下未加 Shift 的 F，立即顯示原有可撤回的 f／ㄑ 預覽。
- 超過既有等待時間後，單次主執行緒截止工作移除預覽並進入分層，不需等放開或另一個按鍵。仍保留原有空分層標記 `·`，避免終端機提前結束 marked text。
- 未輸入任何符號就放開，只還原一次 f／ㄑ。未映射的普通文字會先結束分層，再照普通輸入處理。
- 曾輸入符號後刪空，仍視為已使用，不補 F。空分層的無效鍵與空退格不算使用。
- 焦點、模式、安全輸入或快捷鍵取消時不補字；晚到回呼不能寫入新接收者。
- 計時器比實鍵事件先被處理時，仍以實鍵事件時間保護門檻內的正常打字。Shift＋F 保持英文大小寫用途。

截止工作受主執行緒排程影響，並非硬即時保證。F 預覽是未提交組字；沒有模擬 Backspace 或刪除其他應用程式文字。

## 實鍵驗收（待使用者操作）

1. 在注音與直接英文各短按 F，確認只有一次 ㄑ／f。
2. 按住 F 超過設定時間且不放開：原字應消失，出現空分層標記；放開後原字只恢復一次。
3. 長按後按 R 等映射鍵，放開 F：只有符號，不補原字。
4. 輸入符號後用退格刪空再放開 F：不補原字；完全未輸入符號時按空退格再放開：恢復原字。
5. 快速輸入「其實我是要告訴你怎麼去這裡」，包含門檻內兩鍵重疊；應保持正常注音。
6. Shift＋F 短按及長按、雙 Shift、Ctrl＋數字加詞、快捷鍵、按住 F 時連續退格、離開 App 再返回，確認無回歸。
7. 分別在 iTerm2 與一般文字欄位測試；若焦點離開或切換模式，不應把延遲原字補到其他欄位。

實際畫面更新時機、Secure Input 宿主行為、不同 App 相容性及長時間實鍵使用均尚未驗收。
