# 故障排除

F 長按在本機版本更新後失效：若原字母／注音正常，先確認輸入法選單的輸入監控允許狀態。ad-hoc 簽章更新可能使舊授權不再符合目前 app，即使系統設定開關仍顯示開啟。0.6.0 曾實際發生；只關閉再開啟不足以更新舊識別，需在「隱私權與安全性 → 輸入監控」移除 AI-Bopomofo 舊項目，重新加入 `/Library/Input Methods/AI-Bopomofo.app`，完成系統驗證並重啟輸入法，再由使用者驗收。不要修改權限資料庫或放寬簽章需求。詳見 [授權修復紀錄](progress/f-layer-permission-recovery.md)。

找不到AI-Bopomofo：確認bundle在使用者或系統Input Methods目錄，僅安裝一份，登出登入後重新加入。用scripts/verify-bundle.py檢查資源與識別碼。不能以工具檢查取代實際輸入測試。

安裝程式被阻擋：此為未公證本地版，勿關閉Gatekeeper／SIP。可在本機自行建置後使用安裝腳本；對外發行需另有明確授權的簽署與公證。

英文仍變注音：先用「英文／ASCII組字」或啟用Shift＋字母入口，完成中文音節後以大寫首字觸發。小寫不自動判別。完成英文按Enter回中文。

詞庫候選不更新：使用「重新載入使用者詞庫」，確認格式`MyFPGA _english_myfpga`，UTF-8、5000詞與4MiB限制。原始輸入仍是第一候選，Tab才選補全。匯入中途失敗可檢查本地備份，重試不重複寫入已存在詞。

ASCII取消：選過候選後Esc先還原原字串，再Esc取消；已提交中文不撤銷。候選數字鍵保持數字用途。

Kanata符號失效：不要改F層或重映射；先區分keypad及Unicode事件，記錄應用、組字狀態與符號。本次未驗證真實Unicode路徑，不以猜測修正。

突然提示音：停止hosted／GUI測試，不操作音量；專案已有測試靜音保護，但macOS／Xcode提示來源尚未確認。預設用純邏輯腳本；目前沒有任何自動安裝或播放音訊程序。

AI未啟用：這是研究品質評估後的刻意限制，不是模型下載故障；傳統注音與混打不依賴模型。
