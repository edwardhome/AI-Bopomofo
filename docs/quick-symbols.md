# F 分層與 QWERTY 映射（1.1.0）

## 按下立即預覽，長按才進層

在「偏好設定 → F 分層」開啟「長按 F 輸入數字／符號」。需允許 macOS 輸入監控；本功能不依賴 Kanata。設定頁提供授權入口，驗證由使用者在系統視窗完成。

- F key-down 立即顯示尚未提交的原字：標準注音為「ㄑ」，英文／ASCII 為 `f`。其他注音配置以目前引擎讀音配置產生預覽。
- **門檻內（含等於門檻）放開 F，或按任何下一鍵**：送回原 F 一次，再處理下一鍵。快速 `fr`、`fu`、`fm` 都按原模式輸入，不因重疊提前進層。
- **超過設定時間**且這次等待沒有被正常連打結束：撤回 F 的 marked preview，進入符號層。再按 R 才輸出 `+`，U／M 才輸出 `8`／`2`。
- 撤回只作用於輸入法自己的組字，不向應用傳送 Backspace、不刪除已送出的文件文字。空分層仍使用不提交的「·」佔位，避免終端重送 F。
- F 放開後退出分層。符號先保留在組字，退格可連續刪除；放開 F 才送出。從 ASCII 組字進入時返回原英文組字。

長按時間 100～1000 毫秒，預設 150，設定頁每次調整 25 毫秒；既有個人值不覆寫。計時受系統排程影響，不能保證畫面恰好在門檻當下刷新。事件抵達時也會依事件時間結算，超過門檻仍按符號處理。

## Shift＋F

Shift＋F 不啟動分層，優先使用英文大小寫流程。開啟「Shift＋字母開始英文組字」後，短按保留 `F`，長按字母 F 到首字母門檻可轉成 `f`。此門檻與 F 分層分開設定，同在偏好設定的 F 分層頁。

雙 Shift 的直接英文模式仍將 Shift＋F 交給應用程式處理，沒有輸入法的英文組字或首字母轉換。未按 Shift 的 F 在直接英文與 ASCII 模式仍可長按分層。Cmd／Ctrl／Option／Caps Lock／Fn 快捷操作不啟動分層。

未完成的注音音節、中文選字與 Secure Input 不攔截 F。僅在手勢期間建立被動 F 放開監聽；權限失效時退出分層或送回原鍵，不增加逐鍵日誌。

## 自訂鍵盤映射

「偏好設定 → F 分層」顯示 ANSI QWERTY 實體鍵位：點鍵帽，在下方編輯輸出，按「儲存」。支援最多 16 個可列印字元，包括 Unicode；留白停用該鍵。F、Backspace、Delete、Enter 為控制鍵，不提供改寫。可以還原整張預設映射，操作會先確認。

設定保存於偏好，不修改私人詞庫、不依賴 FM。下一次進入分層才採用新映射；已開始的符號組字固定使用原映射，避免途中換鍵導致不一致。手動「快速數字／符號」也採用自訂映射。選單模式 Esc 為退出；長按模式 Esc 預設輸出反引號，可更改。

## 精簡選單

第一層保留直接英文、ASCII 組字、文字校正、快速符號、工具與詞庫、繁簡轉換、半形標點、偏好設定、更新與關於。繁簡／標點保留第一層以維持原 Cmd＋Ctrl＋G／H 快捷鍵。macOS 自行附加的字元檢視器、鍵盤設定等項目不由本程式控制。

「工具與詞庫…」開啟可捲動的 AppKit 視窗，保留原本 AI 開關、詞庫管理、匯入／匯出、診斷、繁簡與標點設定。使用明確的指令接收者，不依賴曾無法派送 action 的 IMK 巢狀子選單。

## 實鍵驗收（尚待使用者執行）

1. 標準注音按下 F 先看到 ㄑ；短按不出現 f。快速輸入「其實我是要告訴你怎麼去這裡」。
2. 直接英文短按 F 出現一次 f，門檻內 fr 為 fr；先長按 F 再 R 為 +。
3. Shift＋F 長按轉 f，再組 foo；短按為 F。Shift＋S 同樣正常。雙 Shift 來回切換。
4. 長按 F 後測 U／M、Esc、連續退格；以 F 先放、映射鍵先放兩種順序測試，不殘留分層。
5. 將 R 改為 λ²、T 改為 ±，儲存後測試；停用 U、還原預設；重開偏好確認保存。符號可逐字退格。
6. 在 ChatGPT、iTerm2 與文字編輯器測試游標中間插入、焦點切換、快捷鍵與系統授權失效。
7. 開啟工具與詞庫，確認各指令能執行；檢查四個偏好分頁與 QWERTY 鍵帽是否完整顯示。

純模組測試與編譯不等於跨應用實機驗收。
