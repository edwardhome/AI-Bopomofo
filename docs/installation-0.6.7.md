# 0.6.7 開發測試版：F 長按等待時間

安裝 `AI-Bopomofo-0.6.7-dev.1.pkg`（Apple Silicon／Intel 通用），或使用 zip 作為替代封裝。不要同時安裝兩份；此版未經 Apple 公證，供開發測試。從 [0.6.7 Release](https://github.com/edwardhome/AI-Bopomofo/releases/tag/v0.6.7) 取得檔案與校驗值。

1. 保存工作並切換其他輸入法；升級前備份目前 app、偏好與使用者詞庫，保留 0.6.6 安裝包以便復原。
2. 依一般安裝流程執行 pkg；如 macOS 阻擋，依「隱私權與安全性」中該套件的「仍要打開」流程，由本人驗證。
3. 因 ad-hoc 簽章更新，F 分層可能需要透過系統設定移除舊輸入監控項目，再加入目前 `/Library/Input Methods/AI-Bopomofo.app`。不要修改系統權限資料庫。
4. 重啟後先切到 ABC／US，再切回 AI注音；必要時保存工作並登出再登入。
5. 開啟「AI注音輸入法偏好設定 → 進階 → F 長按等待時間」。可選 **100～1000 毫秒**，每格 50 毫秒，初始值維持 100 毫秒。由你自行調整；若易誤觸，可先試 300～500 毫秒。設定保存後，下一次按 F 生效。

## 注音驗收

確認選單的「全英文直接輸入」未勾選，且未在英文／ASCII 組字模式。標準注音鍵盤下：

- 未達所選門檻就放開 F，應顯示「ㄑ」，不直接送出字母 f。
- 等待期間先按其他注音鍵，應先還原 F 的注音，再處理下一鍵。
- 按住 F 超過所選門檻，再按 R，應輸出 `+`；放開 F 後回到普通注音。
- 直接英文／ASCII 模式仍保留 f／F；雙擊 Shift 切換與短按 Shift＋F 的英文行為不變。

本次自動測試 202 項通過、2 項上游跳過；新增注音與偏好整合案例已編譯，未執行 hosted／GUI 自動測試。MacBook Air 的實際打字與設定視窗尚待人工驗收。若 0.6.6 在明確的注音模式真的輸出 f，請記下當時是否有按 Shift、Caps Lock、是否已在 ASCII 組字，以便繼續定位；本次未重現該現象，不宣稱修好未證實的原因。

範例詞庫與原始碼仍隨專案保留。此次不更動 Kanata，也不替使用者改寫 F 等待時間偏好。
