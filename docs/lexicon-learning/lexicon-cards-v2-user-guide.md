# 2.0.0-dev.1 詞彙卡驗收指南

這是獨立功能分支的開發驗收版，未合併或正式發布。安裝由使用者自行決定與操作。

## 開啟與編輯

從 AI注音的「工具與詞庫」開啟「詞彙卡管理」。一張卡代表一個意思，中英、注音、縮寫及符號在同一張卡；中文／英文／術語篩選不會將它們拆成不同資料庫。

1. 按「新增詞彙卡」，輸入詞義與領域。
2. 按「新增名稱」，選擇中文、英文、縮寫或符號。各種名稱可多筆。
3. 中文讀音用 '-' 分音節，例如「銀行」的 `ㄧㄣˊ-ㄏㄤˊ`。多個讀音用 ';' 分隔。延續既有 adapter，中文候選目前一至八字；不修改原生 Ctrl＋9 或原始詞檔，舊詞匯入會列出未收錄行號。
4. 英文輸入碼以 ';' 分隔，例如名稱 semiconductor，輸入碼 semiconductor。符號名稱 SiO₂ 可設定 sio2。非中文名稱不填注音。留白只作對照，不會自動產生候選。
5. 編輯先形成草稿。確認名稱、讀音與輸入規則後按「儲存並套用」，檢查差異並確認。正式版本只在安全組字邊界生效。

「資料與維護」集中匯入／匯出、合併／拆分、移除、回復及舊資料操作；主要畫面不列出 SQLite / JSON 開發細節。合併卡片不代表自動翻譯，建立「相關／上位」關係也不會自動多出輸入規則。

## FM 整理

可選取一至十六張正式或草稿卡片，按「請 FM 整理」。只提供所選卡片，不讀文件或完整詞庫。先啟用原有的「FM 背景整理」設定；沒有模型時仍可手動編輯。

「檢視建議」每項預設不勾選。選取需要的詞義、名稱、讀音或關聯，再「加入草稿」；最後仍須「儲存並套用」。FM 的理由與來源保留，但不當成詞典查證。卡片或正式版本變更會使舊建議失效。名稱共享時，修改一張卡不會改掉另一個意思。

新增的卡片整理是使用者主動操作；原有閒置觀察整理仍只產生舊型態待審建議，不會自動整理或合併所有正式卡片。「資料與維護 → 檢視觀察詞彙」可把已觀察詞建立成草稿，移除不需要的項目後再整理／核准。這不是自動收錄任意原始英文，也沒有新增文件或句子記憶。

## 舊資料、來源與回復

- 「匯入舊使用者詞庫」只讀取既有檔案並建立草稿，保留排除詞與不支援行號報告，不修改原檔。
- 「匯入內建工程詞」建立個人副本，保留來源網址；中文註解不會自行推論成讀音。
- v1 一個詞條先成為一張卡。舊 equivalent 保留為歷史關聯，不自動認定整組都是同義。
- 刪除管理副本後，原始或內建來源可能仍提供候選；不是刪除原生詞庫。
- 回復上一版本沿用五版輪替。首次 v2 遷移的原 v1 版本另行釘選，可用「回復遷移前的原始版本」恢復，不因後續輪替刪除。
- 第一次尚無任何核准詞庫時，沒有可回復的舊核准版本；原生文字詞庫仍保持原樣。

## 新酷音共用

使用「匯出全部」產生獨立 SQLite。若只選部分卡片，僅包含選取卡片的名稱、讀音及內部關聯；跨到未選卡片的關聯會省略。重要完整備份請使用完整匯出。

對方匯入時仍需本機確認。新酷音目前完成 v2 編解碼及雙向合成資料驗證，尚未整合 Windows 介面／候選部署；不能將驗證完成解讀成已可在新酷音正式操作。v1 舊版不能讀 v2 檔案，不能用改副檔名降級。

## 人工驗收清單

1. 新增同一張卡的中文「銀行」／注音／英文 bank；新增另一張「河岸」卡也使用 bank，確認不誤合併。
2. 編輯共享名稱、增加讀音、拆分名稱及移除關聯，檢查其他卡片仍完整。
3. 未儲存時在輸入欄確認候選未改；儲存後確認新組字才取得新詞庫。原文與中文提示分開，提示不進文件。
4. 使用 λ、SiO₂、H₂O 測試候選、移動與刪除，並測試 F、Shift＋F、雙 Shift、Ctrl＋數字及應用程式規則。
5. 開啟 FM 後提出建議，分別取消、只勾一項、編輯後重試舊建議；確認沒有自動合併或自動部署。
6. 關閉 FM 與擴充詞庫，確認傳統輸入正常；再開啟並回復前版。
7. 匯出、匯入、同檔重複匯入；損壞的合成檔應被拒絕，原核准版不變。

沒有執行 hosted GUI、模擬打字或真正 FM 推論；這份清單需由使用者實測。一般英文大詞典、近似拼字與新的直接英文補全模式不包含於這次詞庫架構交付。
