# 本機糾錯與英文上下文預測

0.5.0-alpha 使用 Apple 本機 Foundation Models 提供建議；一般輸入、F 分層與原有技術詞候選不依賴模型。此版為可供人工驗收的候選包，不會自動覆寫已安裝的 0.4.0。

## 手動檢查

輸入一段中文或英文，尚未送出時從選單選「檢查錯字／英文拼字」。中文需先完成注音音節；空白組字、其他特殊模式與 Secure Input 不提供檢查。每次最多 256 個字元、1024 UTF-8 位元組；超限會顯示提示，原文不截斷。

候選視窗永遠把原文放在第一個選項，後面最多三個建議。方向鍵／Tab 可移動選擇，Enter 送出選中的內容，也可使用已設定的選字鍵或滑鼠。Esc 恢復原始組字、游標與中文引擎狀態。檢查尚未完成時繼續打字，會取消檢查並在原文上繼續輸入；此時字母不會誤當選字快捷鍵。檢查完成後，如要繼續修改原文，先按 Esc。

選取建議才會送出文字；不自動修正已提交內容。Apple AI 不可用、拒絕、出錯或逾時時保留原文，英文可顯示系統拼字服務提供的建議。畫面會區分檢查中、無建議、忙碌、逾時與無法使用。這些狀態沒有音效。

## 英文上下文預測

在英文／ASCII 組字中停頓 350 毫秒後，使用當前尚未送出的整段英文作為上下文，預測最多四個單字、32 個字元的續字。輸入法不讀取整份文件，也不把之前已送出的中文或英文保存為上下文。

先顯示通過保護檢查的系統續字建議，再於組字尚未改變時接上 Apple 模型的上下文建議；使用者接受、取消或繼續輸入後不更新舊提示。

第一版使用既有候選視窗顯示「Tab 接受預測；Esc 隱藏」，不把未接受文字插入應用程式的 marked text，也不假設所有程式都能正確顯示內嵌灰字。

- Tab：接受目前預測，續字加入組字，尚未送出。
- Enter：只送出已輸入或已用 Tab 接受的內容；不會暗中接受預測。
- Esc：隱藏預測，保留原文；再次輸入才重新預測。
- 直接打字：沿用原文，丟棄舊預測，再依新內容計算。
- 方向鍵、Home／End、Shift＋Tab：保留原有編輯／候選操作，停止該次預測。
- 沒有預測時，Tab 保持原來的技術詞選取行為。

「英文上下文預測（Tab 接受）」預設開啟，可在主選單關閉。僅對至少三個字元的自然英文、游標在末端且未選取其他候選的狀態工作；偵測到 Markdown 標記、程式碼、路徑、數字或受保護技術詞時不猜續字。這是保守的第一版，不是程式碼補全或 Vim 命令預測。

## 保護與相容性

原始字串永遠保留。建議必須通過長度、字元、重複項目及受保護文字檢查。保護範圍包含反引號程式碼（含尚未閉合的反引號）、網址、電子郵件、路徑、檔名、副檔名、命令旗標、底線變數、混合大小寫識別字、大寫縮寫、數字及現有自訂英文詞。Markdown 標記與空白序列不允許被糾錯建議改掉。

這些規則不能保證每個語意建議都正確，也不能辨識所有未加入詞庫的專有名詞，因此仍由使用者選取。中文模型有可能提出不必要的換詞，不能宣稱已達到自動修正品質。

Foundation Models 使用公開的 SystemLanguageModel.default；需要 macOS 26 以上及可用的 Apple Intelligence 模型。保留 macOS 13 的傳統輸入與系統拼字回退；尚未實機驗證所有舊系統。沒有雲端、Ollama、剪貼簿、全域鍵盤攔截、文件擷取、輸入歷史或私人文字日誌。測試語料都是專案人工編寫的虛構例子。

模型推論全應用最多一筆，五秒軟性逾時（回呼排程可能稍晚）；取消後若底層模型尚未返回，不會疊加新請求。系統拼字服務也以背景 API 執行，最多一筆，等待上限 500 毫秒；實際請求未返回前維持占用。英文預測的等待時間還包含 350 毫秒停頓，不能把模型耗時直接當成從按鍵到提示的延遲。

## 人工驗收清單

1. 尚未送出的中文執行檢查，Esc 返回後繼續輸入，確認既有中文字串與游標沒有遺失。
2. 英文錯字檢查選取建議，確認只送出一次；焦點轉移或 Cmd 快捷鍵不套用晚到的結果。
3. 英文組字輸入 `I would like to `，停頓後查看預測；分別測試 Tab、Enter、Esc 與直接繼續打字。
4. 測試 `src/main.swift`、`qz_module7`、反引號程式碼與自訂詞，不應被改寫或自動延伸。
5. 模型停用或不可用時，確認普通中文、Shift 英文、F 分層與原有候選照常運作。
6. 在 TextEdit、瀏覽器與常用編輯器分別驗證；沒有通過此人工矩陣前，不宣稱跨應用支援已完成。
