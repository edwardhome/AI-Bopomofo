# AI注音輸入法 1.0.3

本次依使用者指定，以第三碼交付長按首字母失效的 Bug 修正版；保留 1.0.1 的時間設定與 SQLite 功能。版本分類見 [共同版本規則](../versioning.md)，已寫入 Mac 與新酷音的 AGENTS.md。

## 回報與修正

使用者回報：舊版長按 S 可轉小寫，1.0.1 改成可調時間後不再轉換。本輪未擷取使用者實際逐鍵紀錄，因此尚不能把單一系統事件認定為已實機證實的唯一原因。

程式檢查發現兩個會讓新路徑失效的條件：

1. 計時器弱持有當次接收者，並要求它與另一個 currentClient 快取是同一物件。回呼接收者暫時未被其他物件持有，或 IMK 代理身分不一致時，會直接取消手勢。
2. 一次 Quartz 查不到按住就取消整個手勢，之後即使收到同字母的實際 repeat，也無法再依門檻轉換；repeat 本身又會被消耗，造成一直保留大寫。

修正後只在本次手勢期間保留接收者，以代次檢查舊回呼是否有效，不依賴代理物件位址或候選視窗的 client 快取。切離、提交、取消、模式切換、開選單或 Secure Input 會釋放接收者並作廢回呼。

Timer 同時查詢當次字母的 session／HID 狀態。確認仍按住才轉換；都無法確認時不改字、不忙等，保留 IMK 實際 repeat／key-up 依原設定時間結算。實際 repeat 若早於門檻，仍不能提前轉換；不輸出重複字母。這個回退情境可能比設定時間晚。
