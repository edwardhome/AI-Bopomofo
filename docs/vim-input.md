# Shift 切換與游標模式提示

0.6.1 起移除本專案新增的 Vim／Neovim／VSCodeVim 自動切換整合與獨立英文系統來源。編輯器使用原有套件管理輸入法；本專案不依編輯器模式切換來源，也不自動開啟鍵盤設定。

## 雙擊 Shift

在 AI注音輸入法內，兩次獨立短按 Shift 切換全英文直接輸入／注音混打。每次按住不超過 250 毫秒，兩次放開間隔不超過 350 毫秒。中間打字、其他修飾鍵、長按或切換輸入欄位都會取消辨識。相同修飾鍵狀態的重複通知會被忽略；持續按住一個或兩個 Shift 只算一次按住，完整放開後才開始下一次。單按 Shift 不切換模式；Shift＋字母依下節區分單字與連續大寫。

切換時在文字游標旁短暫顯示「英文」或「注音」，約 0.8 秒後隱藏；繼續打字、開始組字、失焦、切換來源或收到 Secure Input 下的事件時提早隱藏。提示使用不取得焦點的浮動視窗，不插入文字、不發出聲音。應用若未提供有效游標位置，略過提示；模式仍會切換。選單「全英文直接輸入（雙擊 Shift）」也會顯示目前狀態。

全英文直接輸入把一般按鍵交給應用程式，不組注音、不顯示英文預測。切回注音混打後保留 Shift 英文組詞與本機文字協助。切換時先送出原組字，不接受尚未確認的預測。跨輸入來源或重新啟用輸入欄位時回到注音混打。

## Shift＋字母

先在「偏好設定 → F 分層」開啟「Shift＋字母開始英文組字」。

- 按住 Shift 打 `A`、`B`、`C`：第二個新字母確認為連續大寫，送出 `AB`，之後直接送出大寫。放開 Shift 回注音。首字母先暫存以區分單字入口。
- Shift＋`S` 後立即放開 Shift：保留 `S`，接著可打 `wift` 組成單字。空白會送出單字和一個空白，Enter 只送出單字，兩者都回注音；Esc 取消並回注音。
- 1.0.1 新增：持續按住首字母鍵（例如 Shift＋S 的 S），到達設定時間時將未送出的 `S` 改為 `s`，不重複插入。不是長按 Shift；從「偏好設定 → F 分層 → 首字母轉小寫等待時間」調整 100～1000 毫秒（預設 250），與 F 分層各自獨立；先放開 Shift 但仍按著 S 也可轉換。第二個新字母或其他編輯後就解除首字母追蹤。
- 想打 `mm`：Shift＋M 長按字母 M 轉小寫，放開 M 後再按一次 m。原本放開後 Backspace 刪掉 M、再打 mm 的方式也保留；刪空仍維持英文單字模式。
- 單字中再次按 Shift 可打內部大寫，例如 `iPhone`，不會因此改成連續大寫模式。
- 原先從選單進入的英文／ASCII 組字仍可輸入整句；雙擊 Shift 的全英文直接輸入不受上述單字退出規則影響。

英文單字模式的 Esc 直接取消整段，與選單 ASCII 模式先隱藏預測的操作不同。實際按鍵與不同應用相容性仍需手動驗收。

## F 分層

1.1.0 起未按 Shift 的 F 在中文、全英文直接輸入與英文組詞均保留長按分層。按下立即顯示可撤回的原字，門檻內接下一鍵就是正常打字；超過設定時間才進入符號層。Shift＋F 優先英文 F／f，不啟動符號層；在 Shift 英文組字中長按字母 F 可轉成 f。英文組詞中的符號留在原組字與游標位置，不提前送出。[完整操作](quick-symbols.md)。

F 分層需要輸入監控授權。本機 ad-hoc 版本更新後若分層失效，參考 [授權修復紀錄](progress/f-layer-permission-recovery.md)，透過系統設定重新加入目前安裝的 app。

0.6.6 已由使用者確認雙擊 Shift 可在英文與注音之間來回切換。以下清單仍供不同應用與機器驗收。

## 人工驗收

- 雙擊 Shift 後依序出現「英文」／「注音」，提示靠近游標、約 0.8 秒消失，沒有搶走焦點。
- 顯示提示後立即打字或切換應用，不留下過期提示；AI 候選與既有組字提示不受影響。
- 短按 Shift、大寫英文、Shift 快捷鍵，以及三種文字模式中的 F＋R／放開退出皆保持原行為。
- 開啟 Vim／Neovim／VS Code 不再因本專案整合跳出鍵盤設定。已開啟的舊 Vim 工作階段可在保存工作後正常重開，以移除記憶體中的舊自動命令。

自動檢查與編譯不能代替上述實機驗收；不執行 hosted／GUI 自動測試或模擬打字。
