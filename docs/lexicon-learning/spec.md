# 長期詞彙學習 v1 正式規格

本文件對應 feature/lexicon-learning-v1。基本契約：背景累積、校對後部署；AI 可停用、輸入不中斷。實機驗收尚未完成，不能把開發包視為已通過全部 P0 驗收。

## 開關與輸入行為

依使用者決定，詞彙觀察、FM 背景整理預設開啟；核准擴充詞庫獨立啟用。三者互不依賴。停用背景整理不會停用既有手動文字協助。詞庫不因使用次數、選取一次或外部 approved 標記而自動部署。

中文維持原有自動組句；新增詞只在候選清單附加，明確選取後才覆寫當次 reading grid 節點。第一版拒絕 prefer，不把統計灌入 UserOverrideModel。英文與工程候選維持原文第一、兩字元完整碼、三字元起前綴與最多八個額外候選。擴充候選不覆蓋相同層級的既有候選。

## 觀察契約

只處理輸入法自己的已送出詞彙。不讀文件、剪貼簿、其他應用文字或全域逐鍵紀錄。中文快照來自引擎實際走訪的節點，字與讀音必須逐字對應，最多八音節；英文自動觀察限可追溯的詞庫候選，任意原始 ASCII 或整句不自動保存。無可靠對應、字形轉換、詞彙替換、註音字型註記、尚有未完成音節、取消及 Secure Input 路徑保守略過。

手動選取與自動選取分開；候選預覽不是送出。一般提交不設定 user_confirmed，明確「記住目前詞」才設定，但仍不代表部署授權。IMK insertText 返回只代表已呼叫目標 client，不保證目標應用永久保存文字。

佇列容量 512、單筆最多 8 KiB；生產者使用 try-lock，滿載或鎖忙直接丟棄。背景每兩秒消費最多 128 筆。SQLite 保存彙總與最多 4096 個不含文字的近期事件識別，時間為日級彙總，不保存提交順序。記住目前詞若佇列未接受會顯示失敗。

## 儲存與模型

本機 Application Support/AI-Bopomofo/Learning，與私人 data.txt、自訂同步資料夾分開。SQLite 資料庫上限約 64 MiB，觀察最多 50,000 詞，非明確確認觀察保留 90 天，未確認建議最多 5,000 筆且保留 30 天。每日最多一份自動一致性備份，保留三份；手動匯出的副本由使用者管理。

FM 在獨立 XPC 服務執行。正常打字不等待服務、SQLite、JSON 或磁碟。手動協助與整理共用一個執行名額；取消等待不釋放尚未結束的推論。背景每批最多 16 詞、輸出最多 32 建議，服務提示最多八個；閒置至少 30 秒、每分鐘最多一次，低耗電、熱狀態不正常或 Secure Input 時不啟動。失敗最多三次，間隔至少五分鐘；重新啟用整理可手動重設重試。

正式詞庫是獨立不可變版本檔，不以 SQLite 的可用性作載入條件。舊組字持有原快照，新組字在安全邊界取得新版。外部核准狀態永遠不作為本機授權。
