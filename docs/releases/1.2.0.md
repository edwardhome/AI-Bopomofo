# AI注音輸入法 1.2.0

更新時間：2026-11-14T00:13:14+08:00

## 這次更新

- **Ctrl＋2～9 加入詞組**：在尚未送出的注音組字中，立即將對應字數加入使用者詞庫，不必再按 Enter。例如組字「甲乙丙丁」游標在最後，Ctrl＋2 取「丙丁」。
- **可調整取詞方向**：預設取游標前方，在「偏好設定 → 使用者詞彙 → Ctrl＋數字儲存游標前方的詞」取消勾選，即改為游標後方。範圍不足不截斷或改方向。
- **保留熟悉的操作**：Shift＋方向鍵選取，再按 Enter 加詞仍可使用；新的 Ctrl 快捷鍵支援 2～9 字，原方式維持 2～8 字。引擎可重新選取九字詞。
- **避免錯存與重複寫入**：必須有可靠的文字／讀音對應；不完整注音、標點、重複詞或不適合儲存的轉換模式不強行加入。長按數字不反覆寫入；寫入失敗會回報。
- **F 與英文大小寫沿用 1.1.0**：Shift＋F 優先英文大小寫；未按 Shift 的 F 在門檻內連打仍正常輸入，超過門檻才進入符號層。

Ctrl＋0／1、數字鍵盤及帶有額外修飾鍵的組合不新增為加詞快捷鍵。此操作寫入原有私人詞庫，不會自動同步至版本化 SQLite 管理副本。新酷音已收到相同 F 操作契約，其實作與驗收進度另行追蹤。

## 下載與安裝

- `AI-Bopomofo-1.2.0.pkg`：一般安裝。
- `AI-Bopomofo-1.2.0.zip`：app 備用封裝。
- `checksums.txt`：SHA-256 校驗值。
- `SOURCE-COMMIT.txt`：套件對應原始碼提交。

基本功能部署目標為 macOS 13 以上，提供 Apple Silicon 與 Intel 架構；舊系統與跨應用相容性仍待實測。Apple 模型功能另外需要 macOS 26 以上及可用的 Apple Intelligence。

本版 app 採 ad-hoc 簽章，pkg 未以 Developer ID 簽署，亦未經 Apple 公證。請先核對下載來源與校驗值，再依 macOS 提示自行安裝。這次發布沒有安裝或重啟本機輸入法。
