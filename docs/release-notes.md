# 0.3.1-alpha 本地候選版

新增技術詞候選、Tab／方向鍵選詞、原字串還原、未知詞保留、可選的 Shift＋字母英文意圖入口，以及沿用上游使用者詞庫的專業詞匯入／匯出。保留數字、半形符號與上游注音功能。

未加入自動 AI 排序：Apple FM 研究顯示仍有有害重排與延遲，不符合日常使用驗收。Apple FM 不依賴 Ollama；聊天服務的網路設定與輸入法分開。

純邏輯測試通過；完整 app 與 hosted tests 僅編譯成功。使用者回報突然發聲後，未再啟動輸入法測試，已加入測試專用靜音保護。GUI、Kanata、跨應用、詞庫面板操作仍未驗證，不建立正式 tag。

本地 ad-hoc 簽章、未經公證；尚未公開發行，尚不能宣稱達到 Zing 無感混打體驗。安裝與使用方式見 docs/installation.md、docs/mixed-input.md、docs/dictionary.md。

修正上游事件入口：只有keyDown進入組字，keyUp不重複輸入；恢復修飾鍵鍵盤配置分支。純事件序列測試新增並通過，仍未進行真實GUI操作。0.1／0.2／0.3.0保留作研究回退，不建議安裝日用。
