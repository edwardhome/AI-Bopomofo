## 實作與保護

- `AppInputRuleSettings` 管理版本化、大小有界的本機設定；未知版本或損毀資料回退空清單。規則以 bundle identifier 唯一識別。
- `AppInputModeSession` 在前景 App／程序改變時建立新的設定快照及代次；手動選擇跨同 App 的輸入連線保留，舊代次、錯誤來源及非啟用連線被拒絕。
- `AppInputRuleRuntime` 使用 NSWorkspace 前景通知與 MainActor 狀態，不監聽鍵盤。以目前前景核對通知，不把過期通知直接當成目標。
- 控制器在 activate／setValue 後恢復規則模式；在完整按鍵事件前後檢查安全狀態，不在引擎多段回呼中間切換。關閉、無規則或模式相同時快速返回。
- 未送出的中文、ASCII、候選、F／Shift 手勢與仍由符號層持有的按鍵阻止自動切換；Secure Input、不明前景與連線不符時跳過。不提交文字、不接受模型建議。
- 原有 F 放開監聽、Shift＋F 大小寫及 Ctrl＋數字加詞保留；新功能不新增授權要求、不存取私人詞庫，也不記錄前景 App 歷史。

## 重現方式

```sh
AI_BOPOMOFO_SCHEMA_PYTHON="$PWD/build/lexicon-schema-env/bin/python" \
AI_BOPOMOFO_DERIVED_DATA="$PWD/build/v1-debug" \
AI_BOPOMOFO_PACKAGE_CACHE="$PWD/build/DerivedData/SourcePackages" scripts/test-headless.sh
AI_BOPOMOFO_DERIVED_DATA="$PWD/build/v1-release" \
AI_BOPOMOFO_PACKAGE_CACHE="$PWD/build/DerivedData/SourcePackages" scripts/build.sh Release
AI_BOPOMOFO_DERIVED_DATA="$PWD/build/v1-release" scripts/package.sh 1.3.0-dev.1 Release
scripts/verify-package.sh dist/1.3.0-dev.1
```

Schema Python 環境需包含 `jsonschema`。打包拒絕覆寫既有版本目錄，套件保存 `SOURCE-COMMIT.txt` 與 SHA-256 `checksums.txt`；交付僅複製 pkg 與 app ZIP 至指定版本資料夾。

## 尚未驗證與限制

- GUI 五頁籤版面、App 選取視窗、圖示、跨 App／多分頁／多欄位 IMK 啟用順序、系統來源往返與實鍵均未執行驗收。
- 不以純模組測試宣稱所有 macOS App 相容；延後判斷的單元測試與真實 Secure Input／焦點切換行為分開看待。
- 沒有進行按鍵 P95、長時間操作或 Intel 實機效能量測。Release 為雙架構封裝，不代表已在兩種硬體實測。
- 只有目前 AI注音的有效輸入連線會切換。背景 App、Vim 內部模式、各分頁的程式不個別辨識。
- 未設定規則時保留舊版行為；本次跨欄位的手動模式記憶僅適用於當次有規則的 App。

本專案保留小麥注音來源歷史與 MIT 授權。功能行為參考 Input Source Pro 的 App 規則概念，未引入其程式碼或套件。
