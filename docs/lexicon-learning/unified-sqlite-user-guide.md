# 使用者與工程詞庫操作

適用於 1.0.0 開發版。這是離線管理功能，不需要安裝雲端同步軟體。沒有背景上傳、每週同步或強制上傳。

## 新增中文與工程詞

從輸入法第一層選單開啟「使用者與工程詞庫」。按「新增詞彙」，選擇中文詞、英文詞、工程詞或 Unicode 符號，填寫讀音／輸入碼與實際輸出。

工程詞可另外填「中文別名」及「中文別名注音」。例如 `ch4 → CH₄` 加上 `甲烷／ㄐㄧㄚˇ-ㄨㄢˊ`：選工程短碼可得到 CH₄，輸入該注音可選「甲烷」。中文別名必須有確認過的讀音；中文說明文字不會自動猜讀音變成候選。

按「預覽變更」，查看全部資料，再確認核准。編輯與完整還原的預覽會明示全份替換；一般檔案匯入只合併選取詞及必要關聯。可用「取消預覽」放棄，未核准不生效。不同視窗若已變更詞庫，舊編輯／預覽須重新開啟。

## 把既有詞彙納入 SQLite

- 「匯入原有使用者詞庫」只在你主動點選後，讀取目前設定路徑的 data.txt 與排除詞檔。可辨識中文讀音與 `_english_` 詞，略過排除項，列出無法轉換的行號，再讓你預覽核准。
- 「匯入內建工程詞」將預載短碼與輸出納入管理資料；中文提示不會自動取得讀音。可再編輯並補中文別名。
- 原有文字詞庫、排除檔、上游內建詞庫與引擎近期偏好保留。匯入是建立管理副本，並非刪除或接管原始檔。原檔之後修改，需要重新匯入；原版編輯入口和引擎學習不會因此自動寫入新 SQLite。
- 管理視窗的刪除只刪管理副本；原始詞庫或內建工程資料仍可能提供同一候選。停用工程預載與停用核准擴充是不同設定。

目前中文交換限制沿用一至八音節與可靠漢字讀音對應；超出範圍的原始詞會在匯入報告列出，不會猜測或靜默改寫。

## 換電腦與公司電腦

1. 選詞後按「匯出選取 SQLite」，或用「匯出完整 SQLite」。有關聯的中文與工程詞會一併匯出。
2. 用自行選擇的方式將檔案帶到另一台電腦，不必讓輸入法連網。
3. 另一台使用支援同一 SQLite 格式的版本，按「匯入 SQLite／JSON」，查看新增、重複與衝突，再核准。
4. 一般匯入不刪除檔案未包含的本機詞；要完全取代管理詞庫，另用「完整還原 SQLite」，確認清楚的替換提示。
5. 「回復上一版本」可撤回管理詞庫變更。正在組字的輸入連線會在提交／取消後採用新索引，不強制中斷輸入。

舊 JSON 1.0 仍可交換沒有新關聯的詞條；含中文別名關聯時請使用 SQLite。已發布 Windows 1.1.1 的 JSON 支援不等於已支援本次新 SQLite 容器，須使用完成此功能的後續版本。

## Shift 首字母長按

短按 Shift＋S，仍先得到尚未送出的 `S`。持續按住字母 S，到達設定時間後改成 `s`，持續重複不會變成一串 ssss。從第一層選單「首字母轉小寫等待時間」輸入 100～1000 的整數毫秒，預設 250 毫秒，下一次按鍵生效。這不是按住 Shift 計時，亦不改 F 分層設定。

先放開 Shift、仍按著 S 也可轉小寫；之後正常輸入得到 `swift`。第二個新按下的 Shift 字母仍沿用連續大寫，空白／Enter／Esc 及雙 Shift 的行為保持原有規則。已送出文字不回頭改寫。F 分層仍有原先的優先權，不會因這個功能停用。

實鍵請分別測試短按 `Swift`、長按後 `swift`、連續大寫 `SWIFT`、`mm`、雙 Shift、F＋R，以及 iTerm2／文字編輯器。計時器會確認本次字母仍按住；未能確認時保留大寫。不同應用程式的 key-up／焦點行為需另行實測；無介面測試不等於這些情境已驗收。
