# 0.5.3-alpha 無選單按住 F 分層

長按 F 的分層不再顯示候選視窗或提示選單。超過 100 毫秒且確認實體 F 仍按著才進入，放開退出；不再採用再按 F 切換。從選單手動開啟的快速符號工具仍保留原介面。

查詢來源改用硬體 HID 按鍵狀態。若無法確認按下，回放原 F，不進入可能無法自動退出的分層。這表示系統不提供硬體狀態時長按功能不可用，需要實機確認，不能宣稱已解決所有 macOS／應用相容性。

# 0.5.2-alpha F 分層回歸修正

修正 0.5.1 將系統查詢的「未按下」直接當成 F 放開，可能在 100 毫秒門檻前取消長按的問題。現在只有查詢確實觀察到按下後，才採信後續放開；正常 key-up 仍直接退出。分層中再按一次 F 也可退出，重複按鍵事件不觸發退出。

若應用不傳送 key-up，且系統按鍵狀態不可用，仍須再按 F 或 Esc 離開；不宣稱此限制已完全解決。保留 100 毫秒門檻及原有中文、英文、FM 功能。

# 0.5.1-alpha F 長按修正

F 長按門檻由 200 毫秒調整為 100 毫秒。手勢有效期間檢查 F 是否放開，補救應用未傳送 key-up 時分層可能停留的問題；Esc 離開時也會清除手勢與計時器。短按仍補回原本注音，直接從選單開啟的符號層仍以 Esc／Enter 離開。

新增門檻邊界、漏掉放開事件、短按只回放一次及取消後不重入的純邏輯測試。MixedInputCore 共 18 項通過；實際跨應用按鍵行為尚待人工確認。此候選版不自動安裝、不更改 Kanata、不執行音效或 GUI 測試。

# 0.5.0-alpha 本地候選版

新增選單「檢查錯字／英文拼字」：只檢查當前尚未送出的中文或英文組字，原文固定為第一項，使用者選取後才套用。Esc 返回原文；繼續打字、切換焦點或輸入模式會取消舊請求。

英文組字停頓後顯示上下文續字，先提供系統建議，再接上 Apple 本機模型結果。Tab 加入組字、Enter 不接受尚未確認的預測、Esc 隱藏。第一版在候選視窗提示，未實作應用內嵌灰字。可從主選單關閉預測。

保留 F 分層、Markdown 半形標點、技術詞與所有原有輸入功能。模型不可用時回退原文或系統拼字，不需要 Ollama。保護程式碼、網址、檔名、數字、Markdown 標記與詞庫中的技術詞。

200 筆合成糾錯樣本：中文首項建議符合參考 31／50、英文 50／50、受保護內容 50／50 未提出改動；正確句子仍有 6／50 收到多餘建議。此結果不是實際使用準確率，禁止自動套用。20 筆英文預測只驗證輸出格式與可用性，未評定語意品質。詳見 [評估報告](research/text-assistance.md)。

操作與人工驗收清單見 [使用說明](text-assistance.md)。此包未自動安裝、未推送、未公開發行。保留先前已安裝的 0.4.0。GUI 整合案例僅編譯，沒有執行 hosted／GUI 測試、音效或修改 Kanata。

# 0.4.0-alpha 本地候選版

使用者介面統一為「AI注音輸入法」。主選單保留常用入口，原有詞庫、繁簡、標點與其他選項集中到「進階工具」。上游著作權與授權不變，內部識別碼、詞庫位置、執行檔名稱維持相容。

維持既有 Shift＋字母英文組字、技術詞候選與詞庫匯入／匯出。原始 ji3 顯示與 Vim 專用英文介面依使用者決定暫緩；沒有宣稱能辨識 Vim 普通／插入模式。Apple FM 仍只作研究，不介入輸入。
