# 0.6.6 朋友測試與問題回報

這是開發測試版。請保留原有輸入法，先用沒有重要內容的空白文件測試。不要把密碼、個人詞庫或私人文字貼到公開 Issue。

## 建議順序

1. 記錄 Mac 型號、Apple Silicon／Intel、macOS 版本及測試應用版本。
2. 注音組字與選字：確認原本輸入習慣與注音顯示正常。
3. 雙擊 Shift：英文與注音來回切換，觀察游標提示；測試單按 Shift、大寫 F 及一般 Shift 快捷鍵。
4. 中文標點：關閉「使用半形標點符號」後，Shift＋逗號為「，」、Shift＋句點為「。」；開啟後應為半形。
5. F 分層：啟用選項並允許輸入監控，按住 F 超過 100 毫秒，按 R 得 `+`，放開 F 後正常輸入；另試短按 F、Esc、英文模式。
6. 專業詞彙：使用公開範例測試匯入、重複匯入、英文／ASCII 候選及匯出。這部分仍需更多實機回報。
7. 在 TextEdit、瀏覽器、常用編輯器分別測試，再試切換輸入來源、睡眠喚醒。Vim 使用自己的輸入法套件，本專案不做 Vim 模式自動切換。

沒有可用 Apple 模型的機器仍應能使用基本功能；有模型時再試本機糾錯與英文預測，確認不接受就不改動原文。

```text

Mac 型號／晶片：
macOS 版本：
應用程式／版本：
安裝方式：pkg／使用者層
是否同時啟用 Kanata 或其他鍵盤重映射：
重現步驟：
預期結果：
實際結果：
每次都發生嗎：
```

可附去除私人內容的截圖。若只是 F 失效，先核對輸入監控中的 app 是否是目前安裝版本；重啟後先切到其他來源再切回，詳見[安裝說明](installation.md)。

只有追查雙 Shift 時才手動開啟「診斷雙擊 Shift（20 秒）」；右上角顯示開始提示後，回到同一欄位只按 Shift，測試後再打回覆。診斷檔在使用者快取目錄的 `org.aibopomofo.inputmethod.AIBopomofo/shift-diagnostic.log`，不含文字或一般鍵碼；不必為一般回報開啟它。
