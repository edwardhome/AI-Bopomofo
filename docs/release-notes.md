# 0.4.0-alpha 本地候選版

使用者介面統一為「AI注音輸入法」。主選單保留常用入口，原有詞庫、繁簡、標點與其他選項集中到「進階工具」。上游著作權與授權不變，內部識別碼、詞庫位置、執行檔名稱維持相容。

新增不依賴 Kanata 的 F 數字／符號層：可選的長按 F 約 200 毫秒進入、放開退出，對照原配置的 44 個實體鍵。另提供直接進入的選單與原有功能選單入口。只在輸入法內處理事件，不需要輔助使用權限、不建立全域攔截。細節與限制見 [F 分層](quick-symbols.md)。

以 Markdown 半形輸入為優先：新偏好預設半形標點，反引號直接輸入字元；Big5 與舊版標點清單仍可使用。修正選字鍵下拉選單可能在選取時儲存舊字串的問題，支援選用 asdfghjkl。

維持既有 Shift＋字母英文組字、技術詞候選與詞庫匯入／匯出。原始 ji3 顯示與 Vim 專用英文介面依使用者決定暫緩；沒有宣稱能辨識 Vim 普通／插入模式。Apple FM 仍只作研究，不介入輸入。

自動檢查：C++ 122 通過、2 上游案例跳過；MixedInputCore 15 項通過；CandidateRanking 11 項通過；Python 語料工具 14 項通過；詞庫檢查成功。Debug build-for-testing 與 arm64/x86_64 Release 建置成功。新增 4 項整合案例僅編譯，沒有啟動 hosted／GUI 測試或音效。真實 F 按下／放開、選字設定保存與跨應用行為仍待人工驗證。

本地 app 為 ad-hoc 簽章、pkg 未簽署且未公證，沒有推送或公開發行。
