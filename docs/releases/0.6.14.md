# AI注音輸入法 0.6.14

這版加入預設啟用的 AI 輸入副駕駛，並整合工程與自然科學候選詞庫、長期詞彙觀察及人工核准的擴充詞庫管理。原文與原有注音操作保留，模型建議需明確接受。

## 停頓後自動建議

- 完整中文組字停頓約 700 毫秒後嘗試校正；模型執行時間另計。
- 原文預設選中。Tab 選取建議，Enter 確認；直接 Enter 保留原本提交流程。
- 繼續打字、數字、退格、方向鍵、快捷鍵與 F 先恢復原組字，再處理原按鍵；Esc 隱藏建議。
- 既有詞庫候選優先；沒有候選的英文或技術碼可由 FM 提出拼字及 Unicode 排版建議，例如 `al2o3 → Al₂O₃`。
- 第一層選單「停頓後自動提供 AI 建議」可獨立關閉。模型不可用、忙碌或逾時時不改字。

## 工程詞庫與長期學習

- 預載 103 個工程與自然科學詞條，包含上下標、希臘字母與技術名稱；原文第一、選取才轉換。
- 本機 SQLite 彙總可靠候選詞的使用次數；FM 閒置時提出整理建議。
- 「AI 詞庫管理」提供 JSON 匯出、校對匯入、差異預覽、明確核准、版本回復及獨立停用。
- 未核准資料不部署；不覆寫小麥注音內建詞庫或既有私人詞庫。中文擴充詞採 candidate_only。
- 模型只看目前未送出組字；不保存整句輸入歷史，不擷取文件或剪貼簿，不自動上傳。已送出內容的語境記憶仍是未實作提案。

## 驗證與已知限制

- 本機無介面檢查：288 項通過、2 項既有案例跳過；整合測試僅編譯，Release 編譯與套件驗證成功。
- 主程式及獨立模型服務均包含 Apple Silicon／Intel 架構。
- 真實本機 FM 與獨立服務的四個合成案例，在單獨測試時皆符合預期。服務回應約 0.9～3.1 秒，不包含停頓及候選顯示時間。
- 同時編譯時有兩例逾時，保留原文；四例不代表一般準確率或所有負載下的表現。
- 使用者回報整體打字順暢，但 AI 建議的體感仍不明顯。跨應用完整實鍵矩陣、Secure Input、候選畫面與長時間穩定性尚未全部驗收。
- 傳統輸入的部署目標為 macOS 13；FM 需 macOS 26 以上且 Apple Intelligence 模型可用。舊系統實機相容性尚未完整驗證。
- 附件使用 ad-hoc 簽章，未經 Apple 公證；安裝與既有輸入監控授權操作請依安裝文件，由使用者本人完成。
