# AI注音輸入法 1.0.1

驗證紀錄時間：2026-11-10T00:04:31+08:00

依使用者指定，以 1.0.1 交付，取代本輪開發版編號。本版包含 [統一 SQLite 詞庫](1.0.0-dev.1.md) 與可調首字母長按時間，交付於 `fix/initial-letter-hold-delay`。未合併 main、安裝或發布 Release。

## 操作

從輸入法第一層選單點「首字母轉小寫等待時間（250 毫秒）⋯」，輸入 **100～1000** 的整數毫秒並儲存；設定保留，下次手勢使用新時間。預設為 **250 毫秒**，數值越小越快轉換；F 分層時間不受影響。

Shift＋S 短按保留 `S`；持續按住字母 S 到達設定時間，將尚未送出的首字母轉成 `s`。先放開 Shift、仍按著 S 也適用。後續英文、大寫連打、空白／Enter 提交及 Esc 取消維持原操作。

不再等待系統 repeat，也不變更系統鍵盤設定。系統 repeat 在門檻前後都不會提前轉換或產生一串 ssss。

## 計時與取消

計時只在本次 Shift 英文首字母組字期間有效。Timer 到期時，只確認這個字母是否仍按住；沒有新增全域事件監聽、按鍵記錄或權限要求。IMK 若延後送達放開事件，亦依事件時間結算；不能確認按住時保留大寫。

短按放開、其他新字母、編輯、候選接受、快捷鍵、切換模式／焦點、開選單或 Secure Input 都會結束本次等待。舊 Timer 不可作用到新的首字母。原有 FReleaseMonitor 與分層退出機制未修改。

1. 設為 100／250／1000 毫秒，確認長按 S 的轉換速度有差異；重新開啟選單應顯示儲存值。

3. 測試先放開 Shift 再放開 S、快速連按同字母、mm、退格／候選選取、切換應用、快捷鍵及 Secure Input，不能有延後改字。
