# AI 詞庫管理操作

新酷音與 AI-Bopomofo 的共用個人詞庫操作與限制，見 [跨平台交換與整合紀錄](shared-integration.md)；初始分工與設計保留於 [跨平台個人詞庫設計](shared-personal-lexicon.md)。格式測試與兩端 GUI／實鍵驗收分開記錄。

詞庫管理已納入正式版本，安裝由使用者自行操作。無介面測試與編譯成功不代表所有應用的實鍵驗收完成。

1. 開啟輸入法選單「AI 詞庫管理」。詞彙觀察與 FM 背景整理預設開啟，可各自關閉；關閉觀察仍能使用已核准詞庫。
2. 正常提交可靠候選後，系統背景累積詞彙及次數。直接英文、任意原始 ASCII、整句校正及無可靠讀音的文字不自動加入；這不是完整打字紀錄。
3. 新技術詞可在尚未送出時選「記住目前詞」，核對文字及輸入碼。中文讀音不明時須自己填入確認。這只是待整理資料，不會立刻成為正式候選。
4. 「匯出待整理資料」開啟列表。全選後可取消選取敏感項目，雙擊查看來源及模型推測；按「匯出選取項目」。每個交換檔最多 20,000 詞及 8 MiB，超過時請分批選取匯出。JSON 由你自行傳給 ChatGPT，不會自動上傳。
5. 校對後使用「匯入詞庫 JSON」，先看逐項內容及差異，再選要部署的項目並按「核准選取項目」。外部檔案寫 approved 也不會跳過這一步。
6. 新版本會於下一次安全組字邊界生效，不會中斷正在打的字。中文新詞需選取；工程符號仍是原文第一，選取後才轉換。
7. 「管理擴充詞庫」可選取匯出、刪除詞條及回復上一版本。三者只處理擴充詞庫，不改私人 data.txt 或小麥注音內建詞庫。
8. 「查看學習狀態」顯示資料準備、模型整理與錯誤。背景整理失敗達重試上限時，可關閉再開啟 FM 背景整理以重試；統計與打字不依賴模型成功。

## 給 ChatGPT 的校對要求

請保留 schema_version 1.0.0，核對大小寫、Unicode 語意、注音及單位。把使用者觀察當作使用事實，不把模型原因當成查證來源；不擅自刪除同碼不同義詞。改動 reading 或 text 後依 schema.md 重算 entry_id。沒有依據的條目保留待核對或排除。輸出的檔案仍須由輸入法使用者預覽核准。

## 實鍵驗收

先試一般注音、同音詞、其／去、短 F、長按 F 再接 U／M 輸出 8／2、F＋R、F＋Esc、按住 F 退格、雙 Shift、Shift 英文及中文／半形標點。再試 sio2、i2c、lambda、m2 的 Unicode 選取與編輯。

只以合成詞測試觀察：比較自動提交、候選預覽後取消、手動選取後送出，以及「記住目前詞」的計數。接著匯入範例、取消預覽、正式核准、停用及回復。正在組字時由管理窗部署新版本，回來後原組字必須保留。測試 FM 停用仍能打字及管理詞庫。

Secure Input 與跨應用相容性請以安全的合成測試方式驗證，不使用真實密碼或私人文件作測試樣本；不必把資料庫或輸入內容傳給開發者。
