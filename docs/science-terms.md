# 工程與自然科學候選詞庫

0.6.12 預載 103 個詞條，來自使用者提供的 97 列報告，經逐列整理與修正。這是輸入輔助對照表，不是官方學術名詞認證、公式驗算器或物性資料庫。

## 使用方式

第一層輸入法選單的「工程與自然科學詞庫」預設開啟，可獨立關閉。功能支援：

- Shift＋首字母開始英文單字，放開 Shift 後繼續打字。
- 從選單開啟的「英文／ASCII 組字」。

雙擊 Shift 的直接英文不經過候選；持續按住 Shift 的連續大寫不改變行為。沿用 F 分層規則，因此要輸入一般連續字母時，放開 F 再按下一鍵。

| 目前組字 | 新增工程候選示例 |
| --- | --- |
| `si` | `Si`，不展開其他長詞 |
| `sio` 或 `sio2` | `SiO₂`、`SiO2` |
| `i2c` | `I²C`、`I2C` |
| `fin` | `FinFET` |
| `lambda` | `λ` |
| `m2` | `m²`、`M²`，提示分別為面積及光束傳輸因子 |
| `so42-` | `SO₄²⁻`、`SO4^2-` |

原文始終第一候選。Tab／Shift＋Tab、上下鍵選候選；Enter 提交，Shift 英文單字模式也可用空白提交。中文提示只顯示、不送出。未選候選就提交，會保持原文；不是自動轉換或依大小寫猜測用途。Esc 沿用各模式既有的還原／取消規則。

三字元起前綴補全；兩字元只比對完整短碼，不啟用單字元觸發。查詢忽略 ASCII 大小寫，但相同大小寫的別名優先；例如 `m2` 優先面積，`M2` 優先光束因子，另一種仍可選。所有候選依實際文字去重，最多原文加八個候選。

排序為原文、完整吻合工程候選、既有補全候選、工程前綴候選；同一詞條 Unicode 優先、ASCII 其次。原有自訂英文補全仍從兩字元開始，所以兩字元查詢也可能出現既有私人詞彙。

只比對整個目前組字。`linux/i2c.h`、`my_sio2`、`sio2file` 或 `voltage sio2` 不展開內含片段；也不讀取已送出的文件。ASCII 組字可用來輸入整句，但本版工程候選不提供句內詞彙搜尋。

## 編輯與英文預測

選中 `SiO₂` 後繼續輸入、移動游標或刪除，都保留已選中的 Unicode，不會把 `₂` 過濾掉。刪除遵循完整字元邊界，對 IMK 的游標位置仍使用 UTF-16。一般直接按鍵仍維持原本的 ASCII／度數符號輸入限制；Unicode 來自已驗證候選。

有工程候選時暫停英文上下文預測，避免 Tab 被預測接管，延遲的模型結果也不得覆蓋候選。沒有工程候選時沿用原預測流程。切換詞庫開關會清除預覽選取與預測、保留原文和游標；已藉編輯接受進組字的 Unicode 仍保留。

## 資料邊界與維護

- 預載詞庫是套件資源，啟動使用時一次載入、建立記憶體索引；按鍵處理不讀檔、不執行模型。
- 資源缺漏、格式不符或超出限制時回退既有詞庫，仍可正常打字。
- 不將預載詞寫進私人 `data.txt`；私人匯入、匯出與備份格式不變。這個 JSON 不能直接交給「匯入專業詞彙」的一詞一行匯入器。
- 不提供中文注音詞庫、LaTeX 候選、任意文件自動校正或全域縮寫展開。
- 上下標與希臘字母依碼點校對，不做會把 `₂` 變成 `2` 的 NFKC 相容性正規化。
- 中文是本專案說明性提示，不宣稱全部經 NAER 審定。報告中的物性數值、用途與「法定／嚴禁」敘述未封裝。

[完整詞條表](science-terms-catalog.md) 與 [97 列審核紀錄](science-terms-review.json) 記錄收錄、修正與省略的公式。31 列修正包括：將錯認為下標 B 的 U+2097 排除、用 ℏ 表示約化普朗克常數、區分 H⁺ 與 H₃O⁺，以及不將一般氧化鋁一概標為藍寶石。

原報告僅作詞條來源，不封裝 HTML 或私人對話網址。查證來源的適用範圍也須區分：Unicode 資料驗證字元身分，NIST 驗證單位表示，NXP／MIPI 驗證匯流排名稱，品牌／製造商資料核對拼法；它們不代表替全部中文提示背書。若修改詞條，請同步更新資源、逐列審核與對照表，再執行無介面測試。

## 待使用者實鍵驗收

自動化只測試邏輯並編譯整合測試，不代表已在輸入欄位驗收。

1. 在 Shift 英文及選單 ASCII 模式測 `si`、`sio`、`sio2`、`i2c`、`fin`、`lambda`、`m2`、`so42-`。
2. 先不選候選直接提交，確認原文不變；再明確選 Unicode 候選，確認不帶中文提示。
3. 選 `SiO₂`，輸入 `x`、退格與方向鍵，確認下標不消失；試 `Wi-Fi 6` 的含空白候選。
4. 開啟英文預測時選工程詞，確認 Tab 仍選工程候選；關閉詞庫後確認一般英文補全仍可用。
5. 預覽候選時切換詞庫開關，確認回到原始觸發碼、沒有提早送字。
6. 回歸雙 Shift 直接英文、連續大寫、F＋R、F＋Esc、按住 F 退格及快速注音「其、去」。
