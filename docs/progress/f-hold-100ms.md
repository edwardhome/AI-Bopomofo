# F 長按 100 毫秒與放開恢復

使用者回報按 F 後未返回中文，要求縮短門檻。獨立分支 fix/f-hold-release-100ms，程式 Commit 5164fbf，版本 0.5.1／build 501。

門檻從 200 毫秒改為 100 毫秒，短按保留原注音。既有流程只依賴 IMK key-up；新流程僅在本機 F 手勢有效期間，每約 10 毫秒查詢 F 的系統按鍵狀態，確認放開便退出分層、停止計時。Esc 離開也清除手勢。直接用選單開啟的符號層保持 Esc／Enter 離開。未建立全域事件攔截、未送出模擬按鍵、未保存輸入記錄。

未實機重現使用者的問題；key-up 遺失是程式檢查發現的可能原因，不能宣稱已完成跨應用驗收。仍須測試短按、長按後放開、按住符號鍵先放 F、Esc、切換應用及 Shift 英文。計時器可能受到主執行緒排程影響，100 毫秒是門檻而非精確顯示時間。

驗證：MixedInputCore 18 項測試通過，新增 3 項涵蓋 99／100 毫秒邊界、漏掉放開事件、短按只回放一次、取消與再按。Debug build-for-testing 及 arm64／x86_64 Release 建置成功；首次 Debug 遇舊預編譯快取失效，清除生成的 PCH 快取後重建成功。沒有執行 hosted／GUI 測試或音效。

候選包位於 dist/0.5.1-alpha/。pkg 解包的 77 個檔案與 app 比對一致；識別碼、詞庫、簽章、pkg／zip 校驗通過。包裝工具有 write: Permission denied 提示但成功完成，後續解包驗證通過。app 為 ad-hoc 簽章，pkg 未簽署／公證。

沒有安裝、重啟輸入法、修改 Kanata 或推送。唯讀確認目前系統安裝仍為 0.4.0；需使用新候選版才能驗收本次修正。
