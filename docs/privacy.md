# 隱私

0.5.4 經使用者授權，F 長按使用 macOS 輸入監控權限。僅在輸入法收到 F 按下且開始判定手勢時，建立 session 層級的 listen-only key-up 監聽；系統會送來其他按鍵的放開事件，但程式只讀鍵碼、立即略過非 F 事件，不讀取文字。放開 F、取消、切換應用或輸入來源後移除監聽。沒有螢幕擷取、輸入歷史紀錄、雲端模型或文字上傳。ASCII組字只存在目前輸入狀態；候選字與技術詞庫在本機。一般Debug Log不加入真實輸入內容。

專業詞使用既有使用者詞庫儲存，不建立第二套資料庫。匯入由使用者明確選檔，匯出由使用者選目的地；備份保存在原詞庫目錄。私人詞庫、kanata.kbd、build/dist/artifacts不加入Git。

0.5.0 的手動糾錯與英文預測使用 Apple 本機 Foundation Models，以及系統 NSSpellChecker；僅處理當前尚未送出的組字，不讀取整份文件。英文預測預設啟用，可從主選單關閉。模型不可用時保留原文及系統拼字回退。研究評估只使用合成資料；未作封包擷取或斷網驗證，不宣稱已完成網路稽核。不會在每次按鍵啟動 CLI。

停用上游更新端點避免衍生版本向原版更新。保留上游明確觸發的服務功能；不自動讀取剪貼簿或其他應用文字。本次未修改Kanata或系統鍵盤設定。

選用的「診斷雙擊 Shift（20 秒）」預設關閉，每次手動啟動最多記錄 20 秒、80 筆事件加一筆結束記錄。只記錄事件類別、匿名控制器識別、單調時間、修飾鍵與模式狀態，不記錄文字或一般鍵碼。遇到 Secure Input、到期或寫入失敗即停止；每次啟動覆寫舊檔。檔案位於使用者快取的 `org.aibopomofo.inputmethod.AIBopomofo/shift-diagnostic.log`，目錄權限 0700、檔案 0600，不會自動上傳。
