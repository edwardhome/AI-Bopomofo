# Markdown 與獨立 F 分層

F 長按模式需要「系統設定 → 隱私權與安全性 → 輸入監控」允許 AI注音輸入法。此權限獨立於 Kanata，程式不依賴 Kanata。選單提供「允許 F 分層使用輸入監控」入口；權限已開啟時會顯示「F 分層輸入監控：已允許」。macOS 若要求結束並重新打開，請依提示操作。

在選單開啟「長按 F 輸入數字／符號」（新偏好預設關閉）。F 尚未放開就按映射鍵通常會立即進入分層，第一個映射鍵直接輸入符號，不必等到 150 毫秒；0.6.11 起，注音模式的 ㄑㄧ／ㄑㄩ 在門檻內優先組字，見下節。單獨長按 F 仍在超過設定時間後進入（預設 150 毫秒），沒有候選視窗，放開即退出。短按 F 保留原注音；等待時間內按未映射鍵或快捷鍵，會先把原 F 交回目前模式處理；標準注音為「ㄑ」，直接英文才是 f／F。計時可能受排程影響，不保證顯示或事件處理恰好於 門檻當下發生。

0.6.9 起，按住 F 期間的數字／符號先保留在組字中，按退格可刪除，長按退格可連續刪除；放開 F 才送出。從英文組詞進入時，退格直接編輯原英文組字，放開 F 回到英文組詞。刪除以目前組字為界，不會越界刪除文件既有文字；要刪除既有文字，先放開 F。手動選單模式仍維持原本送出方式。

只在本地 F 手勢期間建立被動放開事件監聽，不修改或阻擋系統事件，不讀取／保存文字。權限不足、監聽建立失敗或被系統停用時保留普通 F／退出分層；不退回切換式的鎖定模式。長按分層內 Esc 輸入反引號，Enter 或切換輸入來源可結束手勢；手動選單模式的 Esc 仍為退出。密碼欄與 Secure Input 不啟用。

從選單「快速數字／符號」手動進入時仍有鍵位選單，使用 Esc／Enter 退出，這是獨立的手動工具。

未完成注音音節或中文選字期間不攔截 F。0.6.0 起英文／ASCII 組詞與全英文直接輸入也支援 F 分層；Shift＋F 短按保留大寫入口，長按啟動分層。Cmd／Ctrl／Option 不套用符號映射。按住數字對應鍵時先放 F，仍抑制舊按鍵的重複事件，避免洩漏注音。

## 快速注音優先（0.6.11 開發版）

標準注音的 F 是「ㄑ」、U 是「ㄧ」、M 是「ㄩ」。高速打字時，前一鍵還沒放開就按下一鍵很常見；等待長按期間的 F→U／M 一律先交回注音引擎，組成 ㄑㄧ／ㄑㄩ，不因按鍵重疊變成 `8`／`2`。

- 想輸入 `8`／`2`：先按住 F **超過目前設定時間**，再按 U／M。
- 想輸入「其、去」：在門檻內接 U／M 即正常組字。等於門檻仍視為等待中；超過門檻則維持符號分層。
- 一旦選擇注音，這次 F 等待就取消；持續按住 F、晚到的計時器或放開通知都不會再切進分層。
- F＋R、F＋Esc 等其他組合仍立即啟動；直接英文、Shift 英文與選單 ASCII 模式維持原行為。
- 判斷使用目前鍵盤配置的單義 ㄑ、ㄧ、ㄩ映射，不把實體 U／M 的例外硬套到倚天、許氏或拼音配置。

這不是 AI 事後改字，也沒有新增等待時間。既有 250 毫秒等設定保持不變；0.6.10 的立即組合鍵會略過長按門檻，所以當時單純調高時間無法改善 F→U／M 的快打誤觸。

## 調整等待時間（0.6.7 起）

開啟「AI注音輸入法偏好設定 → 進階 → F 長按等待時間」，可選 100～1000 毫秒，每格 50 毫秒。0.6.8 起未儲存設定時預設 150 毫秒；已有設定保持原值，由使用者自行決定；長按門檻影響單獨 F 和上述受保護注音組合，不會延後其他立即組合鍵。設定會保存，下一次新按住 F 時生效，正在進行的手勢使用原來門檻。

在標準注音模式下，沒有 Shift 等修飾鍵的短按 F，放開時交回原注音引擎顯示「ㄑ」，不是直接插入英文字母 f。若等待期間先按未映射鍵，會先還原這個注音，再處理下一鍵。按其他映射鍵則立即啟動；單獨 F 達門檻後也可進入分層，放開退出。直接英文與 ASCII 組字保留各自的 f／F 行為；其他注音鍵盤配置仍遵從原映射。

## Markdown 優先

新偏好設定預設使用半形標點；既有使用者的明確設定不會被新版預設覆寫。要使用標準中文逗號與句點，請取消勾選「使用半形標點符號」。單按反引號直接輸入半形字元；Ctrl＋反引號保留 Big5 功能。若有未完成的中文字串，反引號會連同畫面上已有的文字／注音一起送出，不丟字。

原有的標點清單可在第一層選單的「反引號開啟標點清單（舊版操作）」恢復。0.6.5 起工具、詞庫與繁簡選項都放在第一層，避免 IMK 子選單指令失效。

標準注音 `ji3` 對應「我」，目前仍顯示注音符號。原始英文鍵顯示仍暫緩；雙擊 Shift 可切換直接英文模式，Vim 自動整合已移除。

## 0.6.8 的等待與緩衝區

以 150 毫秒設定為例：小於 100 毫秒放開是原始按鍵；100～150 毫秒仍等待，若在這段放開，也保留原始按鍵；超過 150 毫秒才進入分層。因此只有長按門檻需要設定，沒有會吃掉文字的空白區。這是帶緩衝時間的長按判斷，不是電壓比較器的施密特遲滯電路。

等待與空的長按分層會暫時顯示組字標記「·」，讓包含 iTerm2 的輸入欄位知道按鍵由輸入法接管。標記不會提交到文件或終端；短按交回原鍵、長按放開或取消時清除。已有英文組字時保留原組字內容與游標。實機跨應用行為仍需人工驗收。

## 立即組合鍵與快速打字的界線

F 先放開、再按映射鍵，仍是正常連續打字；正在組未完成的注音音節時不攔截 F。除 0.6.11 的門檻內 ㄑㄧ／ㄑㄩ 保護之外，F 尚未放開就按下映射鍵仍視為組合鍵，包括快速打字造成的實體按鍵重疊。程式無法同時將完全相同的事件序列判定為普通文字及符號組合鍵。Cmd／Ctrl／Option／Caps Lock／Fn 不會提前啟動；既有按鍵的自動重複也不會提前啟動。

提前啟動只執行 beginLayer，與門檻啟動相同，不執行 invalidate。F 放開監聽與健康檢查計時器繼續運作，直到放開或原有的失焦、安全輸入及權限失效等取消條件。
