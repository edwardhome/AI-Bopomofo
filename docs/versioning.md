# 版本編號規則

兩端 Codex 與總控依使用者指定的 `X.Y.Z` 分類變更。Mac AI注音與 Windows AI 新酷音共用規則，各自維持版本序列，不要求版本數字相同。

| 欄位 | 變更範圍 | 從 1.2.3 出發的例子 |
|---|---|---|
| X：大版本 | 架構調整、重大功能世代改版 | 2.0.0 |
| Y：功能版本 | 新增功能，或既有功能有根本行為差異 | 1.3.0 |
| Z：修正版本 | Bug 修復、小細節修改、UI 特化與調整 | 1.2.4 |

沒有架構或重大功能改版時，第一碼維持不變。提高前一欄時，後面欄位歸零。單純修復已承諾的行為，不當成新增功能。

使用者明確指定的版本號優先；例如本輪長按 S 失效屬於 Bug 修復，使用者指定交付 **1.0.3**。不自行補發跳過的號碼，也不為了對齊改寫歷史 Tag。

`CFBundleVersion` 是 Mac 內部建置號，持續遞增，與上述三段產品版本分開。設定版本、建立安裝包、推送分支、合併主線及建立 GitHub Release 是不同操作；版本規則本身不擴大發布授權。
